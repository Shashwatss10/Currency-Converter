# Currency Converter
    A simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript.

## Highlights
    - Real-time currency conversion
    - Dynamic country flag updates
    - API integration using ExchangeRate API
    - Responsive UI built with CSS
    - Error handling for failed API requests
    
## Features
    * Convert between multiple international currencies
    * Real-time exchange rates using ExchangeRate API
    * Country flags update automatically based on selected currencies
    * Responsive and user-friendly interface
    * Error handling for API failures

## Technologies Used
    * HTML5
    * CSS3
    * JavaScript (ES6)
    * ExchangeRate API

## Project Structure
    CurrencyConverter/
    ├── index.html
    ├── style.css
    ├── app.js
    ├── codes.js

## How to Run
    1. Download or clone the repository.
    2. Open `index.html` in your browser.
    3. Enter an amount and select currencies.
    4. Click **Get Exchange Rate**.
